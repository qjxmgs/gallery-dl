# gallery-dl 中文下载工作台

使用 Python + PySide6（Qt 6），界面采用左侧配置、右侧下载记录与日志布局。
主窗口保留下载记录和进度，运行日志放在独立的右侧工具窗口中，默认隐藏。
主窗口和日志窗口均使用系统原生标题栏。点击“下载记录”右侧日志图标可显示或隐藏；关闭日志窗口不会清空或停止日志记录。
日志窗口随主窗口移动和缩放，保持外框顶部及高度一致。Windows 拖动期间直接在原生移动消息中同步，不依赖 Qt 定时器；保持固定右侧间距，不在屏幕边缘反复吸附。主窗口最大化时日志显示在屏幕右侧。
依赖固定为 PySide6 6.8.3，已在本项目的 Anaconda Python 3.12 虚拟环境中验证。

在仓库根目录安装可选依赖：

```powershell
uv pip install --python .venv\Scripts\python.exe -r gui\requirements.txt
```

双击根目录 `gui_start.bat`，或执行 `.venv\Scripts\python.exe gui_start.py`。
BAT 优先使用仓库 `.venv`，不存在时使用 PATH 中的 Python。
可运行 `powershell -ExecutionPolicy Bypass -File gui\create_shortcut.ps1`，
在仓库根目录创建带图标的启动快捷方式。快捷方式包含本机路径，不纳入 Git。

每行粘贴一个 HTTP/HTTPS 链接，选择可选的 Netscape 格式 cookies.txt 和下载目录，然后点击开始下载。
链接自动去重并顺序处理。下载目录保留 gallery-dl 的站点子目录规则。
路径偏好由 QSettings 保存在当前用户设置中，仅记录 Cookies 路径，不复制其内容。

“增量下载”每次打开界面默认勾选。使用 gallery-dl 的 SQLite 下载归档，
记录存放在所选下载目录的 `.gallery-dl-archive.sqlite3`，不同下载目录各自独立。
成功下载的文件以及按原规则跳过的本地已有文件会记入归档，失败或未完成的下载不会记为成功。
重复下载相同链接时只下载尚未记录的内容；仍需访问站点解析列表，并非离线跳过整个链接。
已记录内容即使被移动或删除也会跳过；如需补回删除的文件，可取消勾选后再下载。
取消勾选不读写归档，也不删除旧记录，仍保留下载器对本地已有文件的跳过行为。

“按发布日期命名”初始默认开启，默认格式为 `20261113_143025_原文件名.jpg`。
另提供 `2026-11-13_原文件名.jpg` 和 `20261113_原文件名.jpg`，开始下载时记住选项。
前缀使用提取器提供的 `date` 字段，沿用其时间/时区，不用下载时间代替；
没有可用日期时完全保留原命名。这里的原文件名指站点提取器原有命名，包含其作品 ID、序号等。
命名不修改下载归档标识，因此已归档内容依然跳过，不会重命名旧文件。

GUI 使用 `--ignore-config`，保证下载目录、Cookies 和进度行为由窗口配置决定，不自动加载命令行用户配置。
需要代理或其他高级站点选项时，目前请使用原命令行入口。

进度来自下载器回调；未知大小时显示活动进度条，不估算总文件数。
外部下载器是否提供细分进度取决于其实现，GUI 始终显示底层日志。
停止会终止当前下载进程及 Windows 子进程，保留完成文件和下载器产生的临时文件；不提供暂停功能。
下载记录显示最近 2000 条，日志显示最近 10000 行；导出保存当前可见日志。

## 验证

```powershell
.venv\Scripts\python.exe -m unittest gui.test_app -v
```

测试使用本地 HTTP 服务、隔离的设置和 D 盘 QA 目录，覆盖实际下载、跳过、失败后继续、停止、中文路径和进度事件。
